# Dev/test toolchain for the Home Assistant custom integration tests.
# Requires Python >= 3.14.2 (homeassistant 2026.10.4 requires it; verified on 3.14.3).
# This plugin pins homeassistant==2026.10.4, so tests run against HA 2026.10.4,
# which is one minor release behind the live instance (2026.11.1).
# The HA test harness is POSIX-only (homeassistant.runner imports fcntl), so run
# pytest on Linux/WSL/CI; lint/format work on any OS.
# pytest==9.0.3, pytest-asyncio==1.4.0 and the rest of the test stack are pinned
# transitively by pytest-homeassistant-custom-component itself; do not pin them
# here unless a conflict forces it.
# HTTP is mocked with the plugin's own `aioclient_mock` fixture. There is
# deliberately no `aioresponses`: it is broken against aiohttp 3.14.5, which the
# plugin pins, and no test imports it.
pytest-homeassistant-custom-component==0.13.375
ruff==0.17.4
